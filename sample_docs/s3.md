# Storage Guidelines
Documents are stored in Amazon S3 with default server-side encryption (SSE-S3).
Block Public Access is enabled on every bucket; public buckets require a security exception.
Enable versioning on buckets that hold source documents so accidental deletes can be recovered.
Use lifecycle rules to move objects older than 180 days to S3 Glacier to reduce storage cost.
Uploads larger than 100 MB should use multipart upload.
